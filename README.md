# Andorinha — PIC-VTVL

Repositório central do projeto Andorinha (veículo VTVL), integrando documentação, bibliografia, modelos CAD, esquemas de hardware e código-fonte.

---

## 📂 Estrutura do Repositório

- `docs/` — Bibliografia, relatórios técnicos e notas de design.
- `cad/` — Ficheiros 3D, montagens e esquemas mecânicos.
- `hardware/` — Diagramas elétricos, PCBs e esquemáticos.
- `software/` — Código de controlo de voo, simulações e telemetria.

---

## 🛡️ Regras de Contribuição

Para manter a integridade dos ficheiros e evitar conflitos:

1. **Nunca trabalhar diretamente na `main`**: Cria uma branch própria para a tua tarefa (`git checkout -b feature/nome-da-tarefa`).
2. **Submeter via Pull Request (PR)**: Todas as alterações ou novos ficheiros devem ser enviados através de um PR a apontar para a `main`.
3. **Revisão obrigatória**: Nenhum PR pode ser integrado (*merged*) sem a aprovação de pelo menos **um segundo membro da equipa**.
4. **Commits claros**: Descreve sucintamente o que foi adicionado ou alterado em cada commit.
